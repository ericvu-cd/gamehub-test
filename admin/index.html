設定 GitHub 連線

內容資料（Banner／任務／公告／徽章／證書）存在 GitHub repo 裡， 後台需要一組有寫入權限的 Personal Access Token 才能編輯。

到 GitHub 開發者設定 建立一組 Fine-grained token，Repository access 選「Only select repositories」 指定這個 repo，Permissions 裡把 Contents 設為 Read and write， 建立後複製貼到下面（只會顯示一次，請先複製好）。

這裡刻意不用瀏覽器的密碼欄位型態，避免瀏覽器把它當一般密碼儲存， 自動帶到別的網頁的密碼欄位去（例如玩家登入畫面）。
